# Умный бот приёма показаний

Telegram-бот, который:
- Принимает показания естественным языком
- Идентифицирует пользователя по номеру договора
- Обрабатывает фото счётчиков и распознаёт данные
- Использует YandexGPT для понимания запроса

## Установка

1. Установи зависимости:
```bash
pip install -r requirements.txt
```

2. Запусти бота:
```bash
python main.py
```

##  Поддержка фото
Бот принимает фотографии и отправляет их в API для распознавания показаний.
